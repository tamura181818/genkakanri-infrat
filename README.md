# ファイル軽量化アプリ

画像で重くなった **Excel(.xlsx) / PDF** を、見た目や内容はそのままに軽くする社内用Webアプリです。
入札書類など「◯MB以下にして提出」が必要なときに使います。

- 圧縮は画質を下げるだけで、**金額・文言・押印などの内容は書き換えません**
- PDFは **「2MB以下にする」** のように目標サイズを指定すると、自動で調整します
- ファイルはどこにも保存されず、処理してすぐ返すだけです

---

## 社内運用の全体像

> **1台のPCでアプリを動かし、他の社員は社内ネットワークからブラウザで開いて使う**、という形です。
> データはこのPCの中だけで処理され、社外に一切出ません。

```
 ┌─────────────┐        社内ネットワーク(LAN)        ┌───────────┐
 │  動かすPC     │  ← http://192.168.x.x:8501 →      │ 社員のPC   │
 │ (start.bat)  │                                    │ (ブラウザ)  │
 └─────────────┘                                    └───────────┘
```

---

## 準備（動かすPCで、最初に1回だけ）

### 1. Python を入れる
1. https://www.python.org/downloads/ を開き、「Download Python」を押す
2. インストーラを実行。**最初の画面で「Add python.exe to PATH」に必ずチェック**を入れてから「Install Now」
3. 終わったら「Close」

### 2. このアプリのファイルを置く
このリポジトリ一式を、動かすPCの分かりやすい場所（例：デスクトップ）に置きます。
（GitHubの「Code → Download ZIP」でダウンロードして解凍でもOK）

---

## 起動のしかた（毎回）

- **Windows**: フォルダ内の **`start.bat` をダブルクリック**
- **Mac**: ターミナルで `bash start.sh`

黒い画面（またはターミナル）が開き、少し待つとブラウザでアプリが表示されます。

> 💡 **この画面は開いたままにしてください。** 閉じるとアプリが止まります。
> 終了するときは、その画面で `Ctrl + C` を押すか、画面を閉じます。

---

## 社員に使ってもらう

1. 起動すると画面に **`Network URL: http://192.168.x.x:8501`** のような住所が出ます
2. この **URLを社員に伝えます**（メールやチャットで共有）
3. 社員は自分のPCのブラウザにそのURLを入れるだけ。インストール不要で使えます

> ⚠️ **初回の起動時**、Windowsが「このアプリのネットワークアクセスを許可しますか？」と聞いてきたら、
> **「プライベートネットワーク」にチェックして「アクセスを許可する」** を押してください。
> （これをしないと、他の社員のPCから開けません）

---

## ずっと使えるようにするコツ

- アプリを動かすPCは **電源を入れっぱなし** にし、`start.bat` の画面を開いたままにします
- そのPCの **IPアドレス（192.168.x.x）を固定** しておくと、URLが毎回変わらず便利です
  （社内のネットワーク担当者に「固定IPにしてほしい」と頼むと確実です）
- PC起動時に自動でアプリが立ち上がるようにもできます（Windowsのタスクスケジューラ。設定を手伝えます）

---

## 困ったとき

| 症状 | 対処 |
|---|---|
| `start.bat` で「Pythonが見つからない」 | Python導入時に「Add python.exe to PATH」のチェックを忘れています。入れ直してください |
| 他の社員のPCから開けない | ①起動画面の Network URL が正しいか ②ファイアウォールで許可したか（上記⚠️）③同じ社内ネットワークにいるか を確認 |
| ポート8501が使えないと出る | 別のアプリが使用中です。`start.bat` の `8501` を `8502` などに変えてください |
| アプリを止めたい | 起動中の画面で `Ctrl + C`、または画面を閉じる |

## 開発者向けメモ

```bash
pip install -r requirements.txt
streamlit run app.py
```

- `app.py` … 本体（Excel/PDF 圧縮ロジック + 画面）
- `.streamlit/config.toml` … アップロード上限などの設定
- `Dockerfile` … 社内サーバー/クラウドでコンテナ運用する場合に使用

主な依存: `streamlit`, `Pillow`, `pymupdf`
