# 原価管理システム 運用ガイド（バックアップ・保護・復旧）

このガイドは、非エンジニアでも運用・復旧できることを目的にした手順書です。
対象は Google スプレッドシート「原価管理システム」と、取込アプリ（`app.py`）です。

---

## 全体像（どこが入力／自動か）

| シート | 役割 | 入力方法 |
|---|---|---|
| 工事情報 | 工事名・請負額など | **手入力**（所長・管理者） |
| 工種マスタ | 工種・官積算額・数量・単位 | **手入力**（所長・管理者） |
| 見積取込 | 見積を1行ずつ | **アプリの「取込」タブ** |
| 実績取込 | 請求を1行ずつ | **アプリの「取込」タブ** |
| 総合管理表 | 予実・出来高・最終予想・粗利（メイン） | 自動（黄色セルの出来高率・現場見込のみ手入力） |
| 工種別内訳／月次集計（月締）／支払予定／見積一覧 | 集計 | 自動 |

---

## 1. バックアップ

### 1-1. 日次バックアップ（全自動）
毎日、台帳を「バックアップ」フォルダへ日付つきでコピーします（保持30世代、古いものは自動削除）。

**セットアップ（初回1回だけ）**
1. スプレッドシートを開く → メニュー「拡張機能」→「Apps Script」
2. `apps_script/backup_and_protect.gs` の内容をすべて貼り付けて保存
3. 関数一覧から **`setupAll`** を選び「実行」→ 初回だけ権限の承認を求められるので許可
   - これで「数式シートの保護」「日次トリガー登録」「初回バックアップ作成」が一括で行われます
4. 以降は毎日深夜に自動でバックアップされます（時刻は `BACKUP_HOUR` で変更可）

> 個別に実行したい場合：`dailyBackup`（今すぐ1本作成）／`setupDailyTrigger`（自動実行だけ登録）

### 1-2. 上書き前スナップショット（アプリが自動）
アプリの「修正・取消」タブで**上書き保存する直前**に、そのシートの現在値を
`_bak_見積取込` / `_bak_実績取込` タブへ自動退避します（各1世代）。
直後であれば同タブの「⏪ 直前の状態に戻す」で1回だけ元に戻せます。

---

## 2. 数式シートの保護

`setupAll`（または `protectFormulaSheets`）を実行すると、以下が保護されます。

- **保護されるシート**：総合管理表・工種別内訳・月次集計（月締）・支払予定
- **編集できる例外**：総合管理表の「出来高率」「現場見込」（黄色セル）のみ
- **保護しないシート**：工事情報・工種マスタ（マスタ手入力）、見積取込・実績取込（アプリが書込）

これにより、**社員全員が編集権限を持ったままでも、数式を誤って消す事故を防げます**。
日常操作（アプリでの取込、黄色セルの入力）は今までどおりです。

### 工種の追加など、数式シートを直したいとき
1. `unprotectFormulaSheets` を実行して一時解除
2. 変更作業（行の追加・数式のコピー等）
3. 終わったら `protectFormulaSheets` を再実行して保護を戻す

---

## 3. 復旧手順

### 直近の上書きを取り消したい（アプリの修正・取消の直後）
- アプリ「修正・取消」タブ →「⏪ 直前の状態に戻す」

### もっと前の状態に戻したい
1. Google ドライブの「バックアップ」フォルダを開く
2. 戻したい日付のコピー（例 `原価管理システム_2026-07-08_0200`）を開く
3. 必要なシート内容をコピーして本番へ貼り戻す、またはコピー自体を新しい本番にする

---

## 4. 属人化を避けるための約束ごと

- **入力はアプリ経由**を基本にする（列ズレ・重複を防止）
- 数式シートは触らない（触るときは保護解除→作業→保護）
- `app.py` は GitHub で履歴管理（変更・復元が可能）
- Apps Script を変更したら、内容を `apps_script/backup_and_protect.gs` にも反映しておく
- 設定値（税率・工種など）はコードに埋めず、マスタ／設定で管理する
